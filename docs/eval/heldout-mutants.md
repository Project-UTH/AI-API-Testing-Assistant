# Bộ lỗi held-out (mutant) cho API tuyển dụng (cổng 8083)

> Bộ lỗi held-out 17q G0.3, thiết kế 2026-10-23 bởi agent chỉ đọc openapi.json + ground-truth-rules.md. Chỉ dùng để đo một lần ở cuối (G5); không được sửa hệ thống kiểm thử dựa trên file này.

## Quy ước

- Mỗi mutant là **một** thay đổi nhỏ, cục bộ trong code server, bật **riêng từng cái** (các mutant khác tắt). Không mutant nào phụ thuộc mutant khác.
- "Đúng" = hành vi theo `ground-truth-rules.md`; "Lỗi" = hành vi khi bật mutant.
- Token ký hiệu `<hr1>`, `<hr2>`, `<cand1>`, `<cand2>` = token nhận từ `POST /auth/login` của tài khoản tương ứng. `{J1}` = id một tin OPEN do `hr1` tạo (deadline tương lai). `{A1}` = id đơn của `cand1` nộp vào `{J1}`.
- Body tin hợp lệ gốc (gọi là `JOB_OK`): `{"title":"Backend Dev","description":"Mo ta","salaryMin":1000,"salaryMax":2000,"salaryCurrency":"USD","jobType":"FULL_TIME","deadline":"2099-12-31"}`.
- Cột "Bắt được?" là giả thuyết của người thiết kế về một bộ test tự động sinh từ OpenAPI, không phải kết quả đo.
